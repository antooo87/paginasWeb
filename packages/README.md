# packages: código compartido por todas las webs

| Carpeta | Qué contiene |
| --- | --- |
| `theme/` | Diseño común: cabecera, pie, estilos, iconos, huecos de anuncio, plantillas de las páginas legales y generadores de `ads.txt` y `robots.txt`. Un cambio aquí se aplica a todas las webs. |
| `calc-core/` | Fórmulas de las calculadoras en TypeScript puro, con tests (`pnpm test`). Los datos fiscales están en `src/fiscal-es.ts`. |

Aquí no va nada propio de una sola web ni ningún dato personal.
